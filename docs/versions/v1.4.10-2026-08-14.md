# v1.4.10 - 2026-08-14

## 轴反馈与空程轨迹一致性修复

- 文件或工作区切换只重建坐标控件，不再把工程/视图中的轴定义反向写入 Process。坐标面板重建后重放 Process 保存的控制器反馈，并通过正常状态轮询请求最新物理坐标。
- 更新机床轴拓扑和限位时保留同名轴的实时反馈，避免打开文件后面板显示零位、机床模型却保持非零姿态的短暂不一致。
- 空程显示曲线在规划时固化为工件局部坐标，渲染时仅应用一次当前 WPC 变换，使非零姿态生成的空程轨迹与工件保持一致，并能随转台姿态更新。
- CAM→Process 快照缓存分离为完整基础刀路与按加工顺序生成的已规划刀路。重复生成刀路后的后续完成信号不再覆盖同一版本的已验证空程计划；刀路、加工模式、工件安装或碰撞配置改变时仍会正确使旧计划失效。
