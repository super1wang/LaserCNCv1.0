# v1.6.4（2026-08-27）拓扑驱动 BC 运动学与可配置回零

> 本版本以 CMake `project(... VERSION 1.6.4)` 为单一版本源，面向 GTN 模式真实加工前的软件基线验证。

## 交付范围

- 将转台运动学从固定 AC/XYZ 关系改为由轴角色与 `parentAxis` 拓扑驱动，支持 `BASE -> X -> B -> C` 与 `BASE -> Y -> Z` 等刀头/工件分支式 BC 构型。
- 新增刀头与工件承载链的相对直线轴求解、满秩配置校验和正向残差检查，避免把工件侧直线轴错误叠加到控制器 TCP。
- 将机台标定泛化为 `TableTilt`/`TableSpin` 串联转台：根据两条旋转轴参考线求旋转中心，并只沿真实刀头承载链传播切割头校正。
- 调整应用程序设置页面，将切割头外观与碰撞代理参数独立为“切割头参数”页，并修正轴角色等界面文本的翻译上下文。
- 在 Process 参数设置的“运动控制器”根节点下增加“回零配置”子页，按轴配置回零方式、执行顺序和置位坐标，供 Ribbon 回零按钮使用；回零不属于 Process 工作流节点。
- 每轴回零支持“关闭”“控制器回零”和“当前位置置位”。关闭轴完全不调用设备；全部关闭时 Ribbon 直接返回，不连接控制器、不提交设备命令且不产生运动。
- GTN 当前位置置位同步写入编码器与规划位置并回读编码器校验；实际位置改为编码器反馈，旋转轴使用度制脉冲当量，前瞻参数按物理轴分别配置比例。
- GTN 首次使能后按参考实现保留稳定等待，回零按配置顺序串行执行；停止请求可先设置无 SDK 调用的原子取消提示，再进入设备队列安全停止事务。
