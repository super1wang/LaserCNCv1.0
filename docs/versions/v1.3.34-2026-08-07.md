# 加工流程新增循环 Loop 与条件 If 步骤

**版本**：v1.3.34

**日期**：2026-08-07

**状态**：加工流程编辑器新增两类可嵌套的控制节点——「循环 Loop」按设定次数重复执行其子节点，「条件 If」按条件决定是否执行其子节点。两者均允许把其他可执行节点拖拽为子节点，运行语义接入现有工作流执行器，pause/stop/resume 行为不变。

## 本次交付范围

- 新增步骤插件 `LoopStep`（`src/modules/process/steps/loop/loop_step.{h,cpp}`）：参数 `loopCount`（1–99999），`canHaveChildren=true`；执行时仅记录日志，循环次数由执行器展开处理。
- 新增步骤插件 `IfStep`（`src/modules/process/steps/if/if_step.{h,cpp}`）：`canHaveChildren=true`；条件两种模式——
  - 变量 + 正则：从 Start 节点声明的变量取值，用 `QRegularExpression` 匹配，命中即真；
  - IO：对选定输入 IO 读一次，数字量按 `==`/`!=`、模拟量按 `==`/`!=`/`>`/`>=`/`<`/`<=` 比较。
  - 执行时把结果写入 `ProcessStepContext::ifResults`，由执行器据此跳过 false 分支。
- 执行器控制流（`process_workflow_executor.{h,cpp}`）：`collectNode` 改为携带外层 If 链 `ifOwnerIds`，Loop 子节点按 `loopCount` **展开**重复入计划（保持线性步进，pause/stop/resume 语义不变，嵌套 Loop/If 正确）；`runNextStep` 增加跳过循环——任一外层 If 结果为 false 的步骤直接略过不分发。新增 `seedVariablesFromStart`（每次 start 从 Start 节点 `variables` JSON 播种流程变量环境）与 `shouldSkipDueToIf` 辅助；`setStepContext` 把执行器拥有的 `m_variables`/`m_ifResults` 注入上下文。Loop 展开设 `kMaxLoopCount`/`kMaxPlanSize` 硬上限防误填膨胀。
- `IProcessIoService` 新增 `readInput(signalType, ioName, QVariant*, errorMessage)` 一次性读输入（`ProcessIoWorkflowService` 经设备命令队列调用 `readDigitalChannel`/`readAnalogChannel` 实现），供 If 的 IO 模式使用。
- `ProcessStepContext` 新增 `variables`/`ifResults` 两个指针字段；`processNodeTypeCanHaveChildren` 修正为对 Loop/If（及 Group/RunGroup）返回 true。
- UI 零改动复用：Add 菜单按 category 自动列出 Loop/If；树视图拖拽（InternalMove）+ `moveNode` 的 `canHaveChildren` 校验已支持把节点拖成 Loop/If 子节点；双击编辑走插件参数页。持久化经现有递归 children 序列化自动保存，TOML schema 不变（仍 v1，无需迁移）。
- 新增测试 `tests/process_loop_if_executor_test.cpp`（注册为 `lcnc_process_loop_if_executor_test`），覆盖 Loop×If 嵌套、If false 跳过子节点、If true+Loop 三种场景。
