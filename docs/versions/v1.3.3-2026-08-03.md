# LaserCNC Process typed 命令面第一阶段

**版本**：v1.3.3

**日期**：2026-08-03

**状态**：Process typed 设备边界、预检和普通切割安全事务完成，Debug 应用构建、
架构门禁与定向自动化回归通过；物理硬件验证不在本次自动化证据内。

## 本次交付范围

- 为 `ProcessDeviceRuntime` 增加 typed 连接初始化、相对/绝对运动、连续点动、
  单轴停止、轴使能、主界面及 workflow 数字/模拟 IO、回零、断开、预设位及硬件/外设状态快照命令面。
- `ProcessModule` 的手动运动、单轴停止、轴使能、workflow 数字输出、设备连接
  初始化、回零、断开、预设位、轮询及 workflow 单轴/同步多轴运动和停机改为调用该命令面；这些调用路径不再持有 `MotionControl*`、
  `LaserDevice*` 或 `ProcessDeviceCoordinator` lease。
- 保持现有 `DeviceCommandQueue` 优先级与 completion 语义，以及连接失败时的
  安全输出复位和设备断开。
- 新增 `ProcessPreflightService`、不可变 `ProcessPreflightReport` 和 generation
  回传契约；陈旧预检结果仍由 `ProcessModule` 在 GUI 投影前拒绝。
- 新增 `ProcessConnectionService` 和 `ProcessStatusService`：前者承接连接/断开
  命令、进度和完成回调，后者独占 150 ms 控制器状态与 2 s 外设轮询、合并 key、
  防堆积及安全监控生命周期调度。
- 普通切割的硬件 sink 创建/销毁、每轮廓下发前连接/故障/电机创建/轴使能检查及
  控制器轮询均在设备执行线程内通过 typed runtime 完成。
- 删除 runtime 外的 `motionControl()`、`laserDevice()`、`lockDeviceAccess()` 入口，
  并新增架构扫描防止原始设备访问重新逃逸；防御锁只保留在 runtime 私有实现。
