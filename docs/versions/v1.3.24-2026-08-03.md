# LaserCNC 复审问题修复与安全事务回归

**版本**：v1.3.24

**日期**：2026-08-03

**状态**：完成审阅发现的 Process 安全事务、队列/轮询竞态、CAM 稳定标识与 CAD 关闭所有权修复。

## 本次交付范围

- 普通 Stop 仅在 typed executor 确认运动与安全输出复位后进入 `Stopped`；排队或执行失败进入 `Error`。
- EmergencyStop 锁存 stop-only 门禁，禁止交互轴使能和数字输出；显式恢复经设备健康复核后才返回 `Idle`。
- `DeviceCommandQueue` 将 command 与 completion 异常边界分离，保证 completion 最多通知一次；GUI 线程只允许关闭阶段的 Stop 同步事务。
- `ProcessStatusService` 增加 generation 与 pending ticket 取消，旧轮询 completion 不得污染重启后的会话。
- CAM 等价自动加工面按 workpiece entry、role 和签名复用稳定 ID；加工面 AIS 按 document/context 隔离所有权。
- CAD 保存拒绝非活动文档；STL/BREP 在最终取消检查后提交；workspace 关闭守卫在任务超时时拒绝释放 document，单文档替换也会中止。
- 补齐本轮新增安全、恢复、交互 IO 和 CAD 关闭文本的中文翻译。
