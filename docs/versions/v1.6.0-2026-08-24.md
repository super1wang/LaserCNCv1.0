# v1.6.0（2026-08-24）机台安全包与连续碰撞闭环

> 本版本以 CMake `project(... VERSION 1.6.0)` 为单一版本源，应用、模块信息和机台安全包清单同步使用该版本。

## 交付范围

- 使用独立 `lcnc_machine_safety_index` 工具为机台模型生成 `.lmsi`，并通过 QuaZip 原子生成 `.lmsp`。
- 主程序管理包加载、状态、指纹、一键构建进度与失效；工件作为唯一运行时几何变量构建 Job Overlay。
- Rapid、LeadIn、Cutting、Traverse、首刀规划、固定运动和连续点动统一进入碰撞安全接口。
- Process 保持 OCC-free，只消费不可变运动节点、连续证书和短时许可证。
- Coal 作为 Surface-BVH 后的受预算窄相后端；生产连续证书默认不进入在线 OCCT exact。
- 复审全部已跟踪和未跟踪工作区修改，同步架构、审计、交付、待办和碰撞专项文档。

## 主要实现

1. `.lmsp` 强绑定机台模型、唯一 `.lmsi`、索引内容、安全配置和运行时运动学/零件归属指纹；修改机台必要资产后不能继续激活碰撞。
2. `.lmsi` 支持多级稀疏细化、原子检查点、热 APOS 反馈、依赖缓存、叶级 BVH、CertifiedSafe exact 抽样和 schema 5 表面数据持久化。
3. Job Overlay 在工件加载后后台生成局部保守距离场、外包球层级和选择性 Coal 数据；构建、取消、失效和环境代际均采用不可变发布与失败关闭。
4. 连续证书同时绑定阶段、边端点、包键和环境代际。自动刀路生成完成证书后不再重复逐节点 OCCT；用户显式诊断仍可运行审计后端。
5. 模拟锥头/喷嘴改为纯显示对象；碰撞只认机台包内完整 Z 轴切割头几何。空程按每条边的四类安全状态分桶显示。
6. 首刀从实时 APOS 到已提交首轮廓下刀位姿重新规划，并在下发前校验完整连续证书、APOS 漂移、包键和环境代际。

## 工作区审查补强

- 将“全局碰撞开关意图”和“包/Overlay 是否就绪”分离；已启用状态进入重建时，Process 看到 `enabled=true + ready=false` 并失败关闭。
- `MachineSafetyPackageStatus::executionEligible()` 明确要求 `buildInProgress=false`。
- 混合实体/开放面保留完整距离网格，同时使用独立封闭实体网格做点包含；两套三角数据随 schema 5 往返，避免开放面翻转射线奇偶造成假安全。
- schema 3/4 的旧持久碰撞网格要求重建，不沿用旧包含语义。
- 同步多轴流程拒绝混用绝对与相对坐标模式，保证许可证端点与控制器执行一致。
- 清除碰撞诊断中的遗留 `workpiece_proxy/contact_probe` 分支；显示代理不再进入任何碰撞路径。
- 补齐新增异常日志、CMake 头文件清单和碰撞基准生成树约束。
