# 深色主题下拉框可读性修复

**版本**：v1.3.32

**日期**：2026-08-05

**状态**：补全 QComboBox 下拉弹出列表的样式，修复深色主题下"灰底白字"难以辨认的问题。

## 本次交付范围

- 根因：`darkIndustrialStyleSheet` 仅为 QComboBox 编辑框设置了背景，未为下拉弹出列表（`QComboBox QAbstractItemView`）设置任何样式；弹出菜单背景回退到系统默认灰色，而文字颜色被全局 `QWidget { color }` 规则设为浅色，导致灰底白字。
- 修复：在深色与浅色两个主题样式中，分别为 `QComboBox QAbstractItemView`、`::item`、`::item:selected` 补上背景、文字与选中态配色，配色与各自主题的 `QMenu` 弹出菜单一致。
  - 深色：背景 `#24303B`、文字 `#D8E1E8`、选中 `#176B86`/白字。
  - 浅色：背景 `#FFFFFF`、文字 `#243642`、选中 `#D7EDF5`/`#123C4B`。
- 覆盖范围：所有 QComboBox（含 Ribbon 中的 `SARibbonComboBox`，其弹出列表同为 `QAbstractItemView`）。
