# 刀头锥实体渲染修复与外观配置

**版本**：v1.3.35

**日期**：2026-08-07

**状态**：修复刀头锥始终显示为红色线框的根因，并新增刀头颜色/透明度/缩放配置。

## 本次交付范围

### 1. 修复：刀头锥始终为线框（根因）

刀头锥此前无论显示模式如何，都显示为红色线框（8 条母线 + 底圆，线条比完整线框更少），且旋转中心黄球也不再显示。

- **根因**：OCCT 7.9 的 `BRepPrimAPI_MakeOneAxis` 系列构造函数（MakeCone / MakeCylinder / MakeSphere）不再调用 `Done()`，`IsDone()` 在 `Build()` 之前恒为 `false`（`Shape()` 虽能惰性返回有效实体，但不会置位 `IsDone`）。`MachineGuideRenderer::refresh` 在 `Shape()` 之前判断 `coneMaker.IsDone()`，恒为 false，于是**永远走 `else` 线框回退分支**。经诊断程序实测确认：`MakeCone(...).Shape()` 返回 3 面 204 三角形的合法实体，但 `IsDone()=false`；显式 `Build()` 后 `IsDone()=true`。
- `machine_guide_renderer.cpp`：圆锥与中心球构造后显式 `Build()`；圆锥改用默认 +Z 轴构造（`MakeCone(尖半径, 底半径, 高)`）；刀头锥改用 `new AIS_Shape` + `ctx->Display(AIS_Shaded, 0, false)` 显式着色显示，不再经 `displayShape(-1)` 沿用 context 默认模式。
- `gui_application.cpp`：`setCurrentDisplayMode` 中删除遍历全部已显示对象、强制改全局模式的循环（与按域限定的 `RenderingManager::setRuntimeDisplayMode` 重复，且会把刀头锥/球/刀路/gizmo 在切线框时一起拖下水）。工件/机台的逐对象模式切换已由 `setRuntimeDisplayMode` 按域（Workpiece/Machine）处理。

### 2. 新增：刀头外观配置（颜色 / 透明度 / 缩放）

- `app_settings.{h,cpp}`：`ColorSettings` 新增 `cutterHeadColor`（默认红）/ `cutterHeadTransparency`（0–1）/ `cutterHeadScale`（缩放比例，默认 1.0），序列化到 `[colors]` 表的 `cutter_head` / `cutter_head_transparency` / `cutter_head_scale`，沿用 `colorFromHex`/`get_double`/`qBound` 模式。
- `machine_guide_renderer.{h,cpp}`：新增 `CutterHeadAppearance` DTO（颜色/透明度/缩放）与 `setCutterHeadAppearance()`；`refresh()` 用注入的颜色、透明度（`ctx->SetTransparency`）、缩放后的尺寸构建圆锥，替换原硬编码红色。
- `cam_module.{h,cpp}`：`displayAxisGuides()` 每次从 `AppSettings` 读取外观下发渲染器（启动/项目切换即用保存值）；新增 public `refreshCutterHeadAppearance()`。刀头锥不在 `RenderingManager` 域形状内，`Colors` 路径触及不到，故由这里显式下发。
- `dialog_options.{h,cpp}`：颜色配置页新增「刀头」分组（颜色按钮 + 透明度 0–100% 数值框 + 缩放 0.2–3.0 数值框）；`loadFromSettings` 装值、`applyChanges` 收集、`colorModelEqual` 加入三项比较（单独改刀头也判 dirty）；Apply 后若颜色 dirty 调 `cam->refreshCutterHeadAppearance()` 实时重建刀头。大小按用户选择采用「单个缩放比例」（基准 高度30/底半径8/锥尖0.35，scale=1.0）。

### 3. 测试

- 新增 `tests/cone_construction_diag.cpp`（注册为 `lcnc_cone_construction_test`）：断言 `BRepPrimAPI_MakeCone(...).Build()` 后 `IsDone()` 为 true 且得到 3 面、全部三角化的可着色实体，防止该 bug 复发。
