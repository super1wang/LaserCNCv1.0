# v1.4.9 - 2026-08-13

## 机台环境稳定性第一阶段

- 机台文件现在先在后台解析为与 XCAF 文档解耦的 OCC 形体结果；只有读取成功、未取消且仍为最新加载请求时，才在 GUI 线程一次性替换机台文档。旧机台模型在新模型解析失败、取消或被更新请求取代时保持可显示、可用于现有环境校验。
- 增加机台加载代次与“加载中”门禁。加载中不会生成或复用已验证的轮廓间空程计划，避免旧机台几何被误认为新环境的安全证据。
- STEP 装配导入保留直接装配部件作为独立机台实体，支持切割头、夹具、转台和机架分别归轴及设置碰撞角色；不递归拆分零件内部拓扑，控制树节点和渲染对象数量。
- 机台域和文档域重建时，AIS 形体从 OCC Interactive Context 真正移除，而非仅隐藏。反复显示、隐藏、重建和标定刷新不再保留旧 AIS 的选择与图形资源。
- 空程缓存的环境版本现纳入已提交模型身份、机台几何修订、部件归轴及碰撞角色。加载、卸载、手工归轴、角色变更、移动、旋转和删除机台部件会使旧碰撞计划失效。
- 配置中的“下次启动模型路径”与当前已提交模型身份分离；编辑选项或加载失败不会把当前模型的归轴、标定档案和碰撞角色错误套用到另一个文件。
