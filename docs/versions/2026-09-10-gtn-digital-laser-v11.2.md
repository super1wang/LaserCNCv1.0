# GTN 数字量激光控制修复 v11.2

## 范围与原因

用户确认非 RTCP 实机验证通过。理想构型 RTCP 试运行在关闭原生 Pro 激光通道时返回 11091；本项目暂不使用原生激光资源，激光通断统一使用配置的数字量输出。

## 修改

- 理想构型初始化复用 `stopConfiguredOutputs`：按配置极性关闭激光和已配置气路，非法 IO 或 SDK 关闭失败仍阻断，不忽略返回码。
- 删除初始化中的 `GTN_SetLaserEnablePro` 调用。试运行列表的强制禁光、限速保持不变，正常五轴 Group 数字量通断路径不变。
- 旧坐标缓冲兼容入口同样选择数字量；移除原生激光开关调用，误传原生模式时明确失败。激光开启写入当前缓冲区，与关闭路径保持一致。
- 日志版本为 `digital-output-rtcp-trial-v11.2`。
- 新增源代码契约测试，防止重新引入原生激光 API；该测试不替代电气实测。
