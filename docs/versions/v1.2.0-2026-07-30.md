# LaserCNC 架构审计与操作体验收口

**版本**：v1.2.0
**日期**：2026-07-30
**状态**：代码审阅、ACS+GTN Debug 构建和自动化测试通过；GUI 交互、真实激光器和真机加工验证待执行。

## 交付范围

### 架构与死代码清理

- 审计 `src/` 下 346 个 C/C++ 文件及 CMake、测试、脚本和维护文档。
- 删除未接入运行时的草图约束占位器、草图序列化器、平行 ACS/GTN 控制器适配器和默认工具匹配器，共 10 个文件。
- 清除工程树中已经迁移到独立机台树的节点类型、选择、显隐、右键菜单和 item role。
- 加强架构门禁：纯算法不得依赖 UI/文档/Kernel，Process 设备公共头不得泄漏兼容日志，Process 不得恢复 settings singleton。
- CAM、Process、工作流和工具配置解析异常统一写入 `lcnc::Logger`。

### 视图与交互

- 新增线框、着色和带边着色三种启动/新 View 默认模式。
- 新增工件、机台透明度设置；透明度只作用于对应实体，不污染 CAM 辅助实体。
- CAD 几何抓取移动到视图 Ribbon，并将顶点/边/面动作真正映射到 OCCT selection mode。
- 面拾取移动时恢复动态高亮。
- 加工面覆盖层使用独立颜色、边界线、深度层和非选择 presentation，避免遮挡与后续拾取冲突。
- 模拟刀头锥体固定为置顶着色 presentation，避免被机台实体遮挡后只剩线框。

### Process 操作

- 设备连接过程在状态栏显示分阶段进度，完成或排队失败时均正确收口。
- 新增上料位、下料位 Ribbon 动作。
- 上下料位置仅移动设置中显式启用的轴；缺失、非数值、非有限或超行程目标会在下发前拒绝。
- 设备线程再次检查控制器连接、轴创建、使能、回零和运动状态；任一轴下发失败时停止当前运动。
- 动作只在设备已连接且 Process 为 Idle 时启用。

### 运行时部署

- CMake 项目版本更新为 `1.2.0`。
- 将仓库内固定的 `zlib1.dll` 同时部署到应用输出和共享测试/升级器输出目录。
- 运行时快照改为每个输出目录单次复制，消除并行构建时多个测试目标同时复制同一目录的竞争。

## 验证证据

- `cmake --preset acs-gtn`：配置通过，生成器为 Ninja Multi-Config。
- `cmake --build --preset acs-gtn-debug --parallel 16`：通过，成功生成 `x64/Debug/LaserCNC.exe`。
- `ctest --test-dir build --build-config Debug --output-on-failure`：7/7 通过。
- `scripts/check_architecture.ps1 -Root .`：通过。
- `git diff --check`：无空白错误；仅有工作区 LF/CRLF 提示。
- `build/Debug/zlib1.dll`、`x64/Debug/zlib1.dll` 与仓库基准 DLL 的 SHA-256 一致。

- 未执行真实 ACS/GTN 控制器、激光器、IO 和上下料位运动。
- 未执行 GUI 人工回归、Application Verifier、页堆、受控 ASan GUI 和 8 小时资源趋势。
- 本版本可作为集成测试候选，不标记为生产发布完成。
