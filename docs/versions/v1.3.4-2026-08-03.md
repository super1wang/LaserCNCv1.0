# LaserCNC Process workflow service entry slimming

**版本**：v1.3.4

**日期**：2026-08-03

**状态**：Process 工作流文档与流程树 IO 已下沉为独立服务并通过质量回归；
Process 入口整体瘦身及物理硬件验证仍在进行。

## 本次交付范围

- 新增 `ProcessWorkflowService` / `IProcessWorkflowService`，唯一拥有当前 workflow
  schema 文档，并负责新建、加载、保存与变更通知。
- `ProcessModule` 保留 `IProcessFacade` 对外行为和运行编排，但不再直接调用
  `ProcessFlowStore` 或保存 workflow 文档。
- `ProcessFlowTreeView` 的文件操作改经 workflow 服务；节点编辑仍在既有模型层完成。
- `MainWindow` 的流程树改按 `IProcessWorkflowService` 契约接线，不再为该 UI
  路径获取 `ProcessModule*`。
- 架构检查禁止 `ProcessModule` 重新直接使用 `ProcessFlowStore`，并新增 workflow
  service 的新建、保存、加载、空路径拒绝与执行器变更通知回归。
