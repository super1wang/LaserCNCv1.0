# LaserCNC v1.4.1 — 五轴转台分支连续性修复

日期：2026-08-10

## 修复内容

- 修复五轴转台跨轮廓求解时 A/B 倾斜轴可能从 `+90°` 跳变到 `-90°` 的问题。
- 控制器快照布局继续保持 `XYZ/倾斜轴/旋转轴`；恢复上一姿态时按物理父子链显式映射为 `TableSpin` 子轴、`TableTilt` 父轴，不再按布局先后推断旧 `R1/R2`。
- 保持倾斜轴在上一稳定夹持姿态附近，优先由 `TableSpin` 吸收同侧/对侧管材轮廓的周向变化。

## 验证证据

- 新增 AC 转台回归：以前一姿态 `A=+90°` 开始，连续求解同侧与对侧法线，两个点均保持 A=+90°，C 轴承担不少于 90° 的周向变化。
- CMake/Ninja `acs-gtn-debug` 构建通过，完整 CTest 26/26 通过，包含启动冒烟和 SimulatorCMHP。
- Visual Studio/MSBuild `vs-acs-gtn-debug` 构建通过，五轴拓扑/求解回归测试通过。
- 操作者使用实际模型完成基本人工测试并确认通过。
- `git diff --check` 通过。

## 验证边界

- 人工测试属于当前软件与现有机台配置证据；不同机台的旋转中心、轴方向、软限位和物理负载仍需分别验证。
- 本次不改变控制器插补顺序、硬件 RTCP、四轴锁定姿态或其他 Process 设备接口。
