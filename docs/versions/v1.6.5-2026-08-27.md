# v1.6.5（2026-08-27）轴系输入与右手世界坐标隔离

> 本版本以 CMake `project(... VERSION 1.6.5)` 为单一版本源，统一机床轴系输入、OCC 世界坐标与 CAM 控制器输出之间的转换边界。

## 交付范围

- 输入、轴系示教反馈、状态栏坐标、旋转中心和工件安装 XYZ 统一使用控制器轴系坐标；轴系基础零点同时作为转换原点。
- OCC 几何、碰撞、机台变换和角落三轴固定使用 Z 向上的右手世界坐标；控制器正向箭头独立显示，允许 Z 向下形成左手轴系。
- `MachineConfigurationService` 成为轴系点与世界点双向转换的单一权威；旋转轴原点和工件安装平移在进入运动学前转换为世界坐标，标定和自动识别结果在保存前反算回轴系坐标。
- CAM 线性坐标继续按配置的轴正方向投影反求控制器值；配置校验要求 X/Y/Z 正方向彼此正交，但允许右手或左手排列，避免斜交轴系与投影求解产生不一致。
- 新增 `ControllerAxisV1` 持久化约定。旧配置仍按历史世界坐标语义加载，并迁移为轴系输入值，保持已有机台模型、旋转中心和工件安装的有效世界位置不变。
- 标定向导、机台面板、应用设置和状态栏文案明确区分“轴系坐标”与“OCC 右手世界坐标”；中英文翻译同步更新。
- 增加反向 Z 往返、AC 交点固定性、工件安装转换、持久化重载、旧配置迁移、非正交轴系拒绝和 CAM 反向 Z 输出回归。
