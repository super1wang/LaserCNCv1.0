# 版本交付文档

本目录按时间保留不可变的历史交付记录。每次面向版本的交付新增一份
`v<major>.<minor>.<patch>-YYYY-MM-DD.md`，记录当次范围、验证证据和未完成验证。

注意：

- 历史记录描述的是当时状态，不作为当前架构事实来源，也不因后续重构而回写。
- 当前事实以源码、[ARCHITECTURE.md](../../ARCHITECTURE.md)、[AUDIT.md](../../AUDIT.md) 和 [todo.md](../../todo.md) 为准。
- 发现历史记录过时或有误时，在新的交付记录中更正；只有重复且不具历史价值的临时报告才可删除。
