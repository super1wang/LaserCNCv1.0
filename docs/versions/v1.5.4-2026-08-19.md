# LaserCNC v1.5.4（2026-08-19）

## 交付范围

- 修复正常加工始终提示 `CAM could not create an initial approach path`：初始进入规划现在使用首轮廓已应用的真实切割偏置和空程偏置，并补齐五轴协调轴掩码、速度、加速度和加加速度输入。
- 初始进入规划无法生成过渡时，保留规划器的具体失败原因，不再因空过渡快照统一退化为泛化错误。
- 修复 AC/BC 转台刀具偏置重算逐轮廓丢失运动学连续位姿的问题；后一轮廓继承上一轮廓末端完整位姿，保持 A/B 倾斜分支稳定，优先由 C 轴吸收周向变化。
- 增加“控制器实测 TCP 到首下刀点”及“分段偏置重算保持 C 轴优先、避免 A 轴翻转”的自动化回归。

## 根因与边界

- 严格空程输入校验要求空程偏置大于源端和目标端切割偏置，但初始进入调用仍传入零空程偏置，且未填写协调运动配置，因此每次都在几何规划前被拒绝。
- AC/BC 底层求解仍按物理链路使用 `TableSpin(C)` 后 `TableTilt(A/B)`，但刀具偏置应用后的导出快照曾把每个轮廓作为无初始位姿的独立批次重算；管材对侧的等价解因此可能各自选择 `A=+90°` 与 `A=-90°`。
- 本次只修复 CAM 规划和导出快照的连续求解；Process 继续原样执行 CAM 已认证的完整轴坐标，不增加二次 IK、轴重排或控制器侧补偿。
