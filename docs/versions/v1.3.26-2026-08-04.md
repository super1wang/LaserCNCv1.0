# 修复加工时加工面未与轴系一起运动

**版本**：v1.3.26

**日期**：2026-08-04

**状态**：修复仿真/加工时加工面高亮停留在原位、不随轴系运动的显示缺陷。

## 本次交付范围

- 根因：加工面高亮 AIS 在 `CamDisplayProjectionService::refreshMachiningFaces` 中以 `new AIS_Shape(face)` 创建，从不施加运动学变换，且存于独立 map、不在 `GuiDocument::m_displayObjects` 中；`CamModule::refreshMachineTransforms` 每帧刷新工件、CAM 轮廓、刀路、刀轴导轨、行程路径时唯独漏掉加工面，故工件随转台转动时加工面高亮钉在原地。
- `MachiningFaceDisplaySnapshot` 增加 `workpieceEntry` 字段；`CamDisplayProjectionService::State` 以 `FaceEntry{ais, workpieceEntry}` 成对保存，`refreshMachiningFaces` 记录每个面对应的 workpiece entry。
- 新增 `CamDisplayProjectionService::updateMachiningFaceTransforms(document, kinematics)`，对每个加工面 AIS 套用 `MachineKinematics::computeWpcTransform(workpieceEntry)` 并 `SetLocalTransformation` + `RecomputePrsOnly`，与 `applyCamContourTransforms` 对 CAM 轮廓的做法同构；空 entry 退化为恒等变换，空文档/空 kinematics 安全返回。
- `CamModule::refreshMachineTransforms` 的无参与 dirty-axes 两个重载均在 `updateAxisGuideTransforms()` 后调用 `updateMachiningFaceTransforms`，覆盖仿真实际走的 16ms 合并刷新路径；该调用不受刀路可见性限制，与刀轴导轨一致。
- 顺带移除误被跟踪的构建日志 `build_error.log`、`build_output.log`。
