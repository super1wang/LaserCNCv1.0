# LaserCNC CAM 五阶段流程交付

**版本**：v1.1.0
**日期**：2026-07-30
**状态**：代码构建与自动化测试通过；UI 实际操作和实机加工验证待执行。

## 交付范围

- 建立“分离加工面 → 提取轮廓 → 离散点 → 几何刀路 → 机床坐标”的持久化五阶段 CAM 状态链。
- 加工面与横截面统一为工件实体面组；横截面作为内部工艺数据参与交线、法线和 A 轴求解，不在项目树或视图中显示。
- 加工面根节点支持显示/隐藏；关闭或切换工程时清理旧工程运行时面组并按新工程持久化记录重绑。
- 平面和管材共用面组驱动的轮廓提取接口；手动加工面组提取时剔除组内共享边，避免将 CAD 面分割接缝生成刀路。
- 自动生成使用一个可取消后台 Task，报告五阶段总进度；手动阶段保持独立 Task。
- 自动 Task 冻结并复核加工面组、提取策略、机台配置、装夹关系和工件源；输入变化时丢弃结果。
- Process 导出要求五阶段完整、未过期，且每阶段输入 revision 与上游 revision 连续。
- 刀路参数与机床坐标拆分为独立 Tab；轮廓起点、重新计算、刀路预览仅保留 Ribbon 入口。
- 持久化加工面角色、阶段状态、失败原因、轮廓点、加工面法线、横截面法线、切向量、引刀线及机床坐标。
