# 统一 Stop 软件安全停机与停止复位

**版本**：v1.3.25

**日期**：2026-08-03

## 本次交付范围

- 移除独立的软件急停入口、状态和复位急停入口；`Stop` 成为人工停止与加工期严重错误共用的唯一软件安全停机事务。
- Stop 通过 `DeviceCommandQueue` 的最高 `Stop` 优先级，取消尚未执行的工作流、交互、普通和轮询命令，停止工作流、轴系与运动缓冲，并关闭激光设备发射/指示光以及数字量激光、吹气/二路吹气；夹头、冷却和其他 IO 不受 Stop 强制改写。
- 运行中轴失能和工作流节点失败进入同一 Stop 事务，安全停机完成后保持 `Error`；人工 Stop 完成后进入 `Stopped`。
- 新增“停止复位”命令：Error 状态先复查加工配置（例如图层未配置工具），再在设备执行器中再次执行安全停机并检查轮廓边界健康状态；只有全部通过才恢复 `Idle`。
- 移除状态切换的隐式安全停机副作用，暂停不再额外停止轴系。
- 修复后台预检或运行期错误后的 Ribbon 状态同步：状态机变为 `Error`/`Stopped` 时立即重新计算命令状态，停止复位按钮可用。
- `stop-only` 队列门禁只覆盖安全停机事务本身；安全停机成功后（包括最终状态为 `Stopped` 或 `Error`）立即恢复全部队列通道。停止复位仍执行健康检查，但不再长期锁住手动指令。
