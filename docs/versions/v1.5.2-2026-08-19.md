# v1.5.2 — CAM 统一运动计划与稳定碰撞验证

日期：2026-08-19

## 本次交付

- CAM 成为切割、引入、轮廓间空程和最终物理轴坐标的唯一生成端。切割偏置与空程偏置迁入 CAM 参数，沿局部法线构造；空程明确拆分为 Retract、Traverse 和 Approach。
- Process、ACS、GTN、PureSimulation 与离线仿真改为只读消费已提交运动快照，不再重排、重新求解或叠加工具高度。首轮廓进入路径通过控制器 APOS 请求 CAM 临时规划，并在执行前校验轴漂移。
- 启用碰撞检测时，全局生成刀路事务覆盖引入、切割和空程节点，完成后原子发布运动计划与碰撞状态；仿真直接复用 CAM 节点状态和碰撞区间。
- 修复 `BRepExtrema_ShapeProximity` 在当前 OCCT/jemalloc 运行时中的析构访问冲突。所有精确 OCC 运算经过唯一进程级门禁，扫描不执行常规布尔求交。
- 增加外表面三角网格压缩、只读 BVH、AABB/OBB 分层筛选和离散姿态最多四线程并行。只有网格误差带内候选进入 BRep 精确距离，并保留封闭实体包含关系检查。
- 增加 CAM 运动计划、碰撞策略、OCCT 精确锁、真实半球碰撞和表面 BVH 并发性能回归；`model/` 中的半球、AC 转台、切割嘴及其它代表性 STEP 作为统一测试资产纳入版本。

## 验证证据

- `cmake --build --preset acs-gtn-debug --parallel 16`：Ninja Debug 全量构建通过，应用输出位于 `x64/ninja/Debug/LaserCNC.exe`。
- `ctest --test-dir build-cmake -C Debug --output-on-failure`：35/35 通过，包含架构门禁、启动烟测和 SimulatorCMHP SDK 集成测试。
- 半球刀路规划保持在 5 秒门限内；10,000 个旋转锥头/半球表面 BVH 姿态约 2.4–3.0 秒。
- ASan preset 全量构建通过；表面 BVH、OCCT 精确锁、半球碰撞、碰撞策略及快照并发相关测试通过。
- `git diff --check` 通过；Process OCC-free 门禁通过。

## 已知限制与后续工作

- 非机台模式人工测试基本通过；完整机台模式仍存在严重耗时，下一版本需要按轴刚性组进一步压缩、缓存和量化候选/精确复检次数。本版本不把非机台性能结果视为完整机台验收。
- 当前校验以最终离散运动节点为主，尚未完成连续段扫掠或保守细分，也不会在碰撞后自动重规划路径。
- 未完成代表性 AC/BC 转台、摆头和真实切割头的低速无激光实机验证，以及 100 次 GUI 循环和长期资源趋势测试。
