# LaserCNC v1.4.3 — Process runtime 与模块依赖收口

日期：2026-08-11

## 交付范围

- 删除运动 sink、纯仿真 ticker/sink 和普通切割管理器对 `ProcessModule*` 的反向持有，改为位置投影、进给倍率、仿真状态和活动状态的窄回调。
- 将 `ProcessDeviceRuntime` 的设备会话/安全停机与配置表加载职责分别拆分到 `process_device_session.cpp` 和 `process_device_configuration.cpp`，保留同一 runtime 所有权、设备协调锁和 SDK 生命周期边界。
- 扩展架构门禁，禁止 Process runtime/sink/cutting 公共 contract 再暴露 `ProcessModule*`，并同步更新架构说明与待办事实。
- 代码审查中将普通切割活动标志改为作用域自动复位，覆盖成功、停止、错误和异常返回；原子状态回调保持非阻塞，避免 GUI 线程等待工作流退出时形成阻塞调用环。

## 验证边界与后续事项

- SimulatorCMHP 结果仅作为 ACS SDK 模拟器证据，不等同于真实 ACS/GTN 控制器、激光器、硬接线急停、长期运行或内存稳定性验证。
- 本次保持 Stop 为唯一软件安全停止入口，仍只强制关闭激光与吹气输出；未改变控制器指令、加工状态迁移或真实设备参数。
- `ProcessRunCoordinator` 对完整 run/preflight/Stop/Emergency/Recovery 状态事务的进一步下沉，以及 motion sink 生命周期隐藏到 typed executor 私有 contract，仍保留在 `todo.md`。
