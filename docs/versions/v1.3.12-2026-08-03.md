# LaserCNC project explorer projection contracts

**版本**：v1.3.12

**日期**：2026-08-03

**状态**：工程树从具体 CAD/CAM Module 依赖迁移到只读投影服务。

## 本次交付范围

- 新增 `ICadProjectExplorerProjection` 与 `ICamProjectExplorerProjection`；模块通过
  非拥有 adapter 服务注册其只读快照，避免现有 `ServiceRegistry` 的具体模块服务
  生命周期发生变化。
- `ProjectExplorerModel` 不再 include 或接收 `CadModule*`/`CamModule*`，而是只消费
  文档、草图、刀路图层/轮廓、pipeline 与加工面快照。
- `AppContext` 为窗口边界提供 projection contract；`MainWindow::rebuildProjectExplorer()`
  改经该契约调用。节点 key、树恢复、选择与显示行为保持不变。

## 验证证据

- 串行 quality `lcnc_app` 和 `LaserCNC` 构建通过。
- `architecture_checks`、CAD 算法契约、刀路生成服务和启动冒烟：4/4 通过。

## 后续
