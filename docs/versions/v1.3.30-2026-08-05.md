# 工程树图层操作与选择状态保持

**版本**：v1.3.30

**日期**：2026-08-05

**状态**：工程树不再支持拖拽重排；新增图层创建、批量移动轮廓到图层及删除图层（同时删除其下轮廓）的操作，并避免程序化拾取同步意外展开折叠节点。

## 本次交付范围

- 工程树：禁用节点拖拽，避免误触导致轮廓顺序变更；轮廓重排仍由显式命令承担。
- 图层：在刀路根节点右键可新建图层；在图层右键可将当前视图/工程树选中的轮廓批量移动到该图层，或经不可逆确认后删除该图层及其轮廓。
- CAM 数据与显示同步：批量移动只进行一次归属同步和通知；删除图层会同步更新 XCAF CAM 实体、AIS 显示、渲染、选择状态和下刀预览，并始终保留至少一个空图层。
- 工程树状态：重建时保留多选和当前项；从视图同步选择轮廓时不会自动展开折叠的父节点。
- 国际化：新增图层操作和确认提示均已加入中文翻译表。
- 回归测试：扩展 `lcnc_cam_data_manager_test` 覆盖批量移动、删除图层及保留空图层；扩展 `lcnc_project_explorer_controller_test` 覆盖多选/当前项保持与折叠节点选择。
