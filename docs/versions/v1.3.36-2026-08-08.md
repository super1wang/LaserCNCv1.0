# 加工流程新增轴系置位插件

**版本**：v1.3.36

**日期**：2026-08-08

**审阅日期**：2026-08-09

**状态**：审阅通过。流程步骤新增"轴系置位"插件，运行时将所选轴当前位置寄存器直接重写为指定坐标（ACS 调用 setfpos，GTN 同步设置编码器与规划位置）。

## 本次交付范围

### 1. 新增 `SetAxisPosition` 流程节点（轴系置位）

在加工流程中可插入"轴系置位"步骤，选择若干轴并各自设置置位坐标，运行时将所选轴的当前位置寄存器直接重写为指定坐标（不产生运动）。典型用途：回零后或手动对刀后重定义当前坐标。

- `process_node_type.h` / `process_node.cpp`：新增 `ProcessNodeType::SetAxisPosition` 枚举值与 `to/from` 字符串转换（工程按字符串持久化，旧工程不受影响）。
- `set_axis_position_step.{h,cpp}`（新文件）：步骤插件实现 `IProcessWorkflowStep`。
  - 参数：`axes`（`{axis, position}` 行表）+ `timeoutMs`（默认 5000）。
  - 编辑器：表格（轴 / 置位坐标 / 操作），"添加轴"按钮 + 超时数值框，沿用 `multi_axis_move` 的表格模式。
  - 摘要：`置位 X=0.000, Y=5.000`，空表显示 `置位（空）`。
  - 执行：调用 `context.motion->setAxisPosition(rows, timeoutMs, errorMessage)`。
  - 分类："运动"（`sports`），与单轴/多轴运动同组；执行器键 `setAxisPosition`。
- `process_step_builtin_registration.cpp`：注册 `SetAxisPositionStep`，"添加"菜单与编辑对话框经步骤插件机制自动接入（无需改 UI）。
- `CMakeLists.txt`：加入新源文件。

### 2. 设备层 `MotionControl::SetFPosition`

`motion_control.h` 新增纯虚 `SetFPosition(Axis, double)`，各控制器实现：

- **ACS**（`acs_motion_control.cpp`）：调用 `acsc_SetFPosition(m_hHandle, AxisIndex, dPos, NULL)`（即 setfpos），按用户单位直接写入反馈位置。
- **GTN**（`gtn_motion_control.cpp`）：mm→脉冲换算（`MillimeterToPulse`）后，同步调用 `GTN_SetEncPos`（编码器反馈位置）与 `GTN_SetPrfPos`（规划位置），再调用 `GTN_SynchAxisPos` 使寄存器值对轴生效。三步均检查返回值；`GTN_SetPrfPos` 与 `GTN_SynchAxisPos` 已在 `Enable()` 中使用，沿用同一接口。
- **Simulator**（`simulate_cmhp_motion_control.cpp`，all-off 分支）：直接写入本地 `AxisState::position`，与 `MoveAbsolute` 一致；ACS 版 `SimulatorCMHP` 继承自 `ACSMotionControl`，自动复用 setfpos 实现。

### 3. 运行时 / 运动服务

- `process_device_runtime.{h,cpp}`：新增 `setAxisPositions(QVector<QPair<Axis,double>>)`，经设备协调器锁内一次性置位多轴。写入前先完成整表校验（连接、轴注册、有限数值、重复轴），避免后续行非法时留下前面轴已经置位的半完成状态，再逐轴调用 `SetFPosition`。
- `process_step_context.h`：`IProcessMotionService` 新增 `setAxisPosition(QVariantList, int timeoutMs, QString*)`。
- `process_workflow_services.cpp`：`ProcessMotionWorkflowService::setAxisPosition` 解析轴名（`enum_cast<Axis>`），经 `executeDeviceCommand`（Workflow 优先级）下发，BASE 等未注册轴名返回"轴未注册"。

### 4. 加工控制面板分组与翻译

- `widget_laser_control.{h,cpp}`：原控制页拆分为"加工控制"和"设备控制"两个标签页；运行/暂停/继续与停止按钮使用一致尺寸并居中排列；轴位置、手动点动和 IO 状态移入设备控制页。
- `translations/lasercnc_zh_CN.ts`：补充新标签页以及轴系置位步骤、校验错误的中文翻译；源代码保留英文源串和相邻 `// 中文翻译：...` 注释。
