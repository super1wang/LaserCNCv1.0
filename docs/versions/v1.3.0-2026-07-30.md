# LaserCNC 阶段性结构与自动化收口

**版本**：v1.3.0
**日期**：2026-07-30
**状态**：阶段性源码、格式与自动化门禁可提交；生产发布验证未完成。

## 本阶段范围

- 应用自有格式收紧为 `.lcnc`/CAM v4、当前 workflow schema 和
  Process settings schema v2，删除产品内离线升级器、历史迁移与双读双写。
- Process 文件和目录迁移为 snake_case，删除兼容消息/日志层与 legacy
  workflow service 别名。
- `DeviceCommandQueue` 增加唯一命令 ID、五级优先级、同级 FIFO、同 key
  合并和完整 completion 状态；每个被接受的命令只完成一次。
- 引入执行线程私有的 `ProcessDeviceRuntime` 和运行状态
  `ProcessRunCoordinator`，并调整模块关闭顺序。
- MainWindow 下沉 workspace、工程树和视图状态 controller；CAM 增加带
  revision 校验的 `ToolpathGenerationService`；CAD 算法统一异常边界。
- 增加当前格式拒绝、队列/状态机、CAD/CAM、不可变刀路快照、UI controller、
  启动冒烟及真实 SimulatorCMHP SDK 集成测试。
- 建立项目 `/W4`、质量 `/WX`、独立构建矩阵和统一
  `scripts/run_quality_gates.ps1`。

## 阶段性审阅修正

- 修正同 key 合并时复用旧命令 ID 的问题：被替换命令返回
  `Superseded`，新命令取得独立 ID 并独立完成。
- 修正 Process 停机时监控停止晚于设备断开的顺序。
- 修正机械重命名导致的 OCC 头文件
  `XCAFDoc_DocumentTool.hxx`/`XCAFDoc_ShapeTool.hxx` 大小写错误，避免在
  区分大小写的文件系统上失败。
- 对照计划重新核对未完成范围，不将构建、Simulator 或软件测试证据写成
  物理硬件验证。

## 验证证据

- Ninja 独立子生成树：
  - all-off：16/16 CTest。
  - ACS-only：17/17 CTest。
  - GTN-only：16/16 CTest。
  - ACS+GTN quality（项目 `/W4 /WX`）：17/17 CTest。
  - real-laser：17/17 CTest。
  - ASan ACS+GTN：17/17 CTest。
- Visual Studio/MSBuild ACS+GTN Debug：构建及 17/17 CTest 通过。
- SimulatorCMHP 测试实际调用 `acsc_OpenCommSimulator()`，加载部署的
  `Simulator.prg`，完成 100 次设备线程会话命令和同线程断开/销毁。
- 架构、旧格式/旧 API、Process-OCC、CMake 收录及空白检查通过。

## 未完成与验证边界

- Process 唯一 typed executor 尚未完成：阶段性静态扫描仍有 41 处 runtime
  外的设备锁或设备指针使用；`ProcessDeviceCoordinator` 继续作为防御锁。
- `ProcessModule` 的 connection/preflight/status、CAM 的 machining-face /
  calibration / display projection，以及 CAD 文档 IO/建模/选择 controller
  仍待继续下沉。

- ACS、GTN 和真实激光物理设备的连接、加工、暂停、Stop、急停、断开与安全
  输出复位未验证。
- real-laser 旧协议适配器仍有项目 `/W4` 告警，尚未达到该配置 `/WX`。
- Application Verifier/页堆、受控 ASan GUI、8 小时资源趋势和性能门限未完成。

剩余实施项以 `todo.md` 为准；详细证据边界见 `AUDIT.md` 和 `DELIVERY.md`。
