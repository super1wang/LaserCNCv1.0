# LaserCNC v1.4.0 — 多构型运动学与项目 v5

日期：2026-08-10

## 交付范围

- 分离物理机床拓扑与项目加工模式，引入显式轴角色、能力集合、模式定义、锁定姿态和固定容量轴布局。
- 闭环 `Planar3Axis`、`RotaryTube4Axis`、`SimultaneousTable5Axis`，并提供 `SimultaneousHead5Axis` 软件 TCP 求解；XYZAC/XYZBC 支持三轴、锁定倾斜轴的四轴和五轴模式。
- CAM 统一通过 `solveToolpathForOrder` 求解有序轮廓，快照携带五元素位姿、参与掩码、轴布局、加工模式、求解器 ID/版本及求解时机床指纹。
- Process、ACS、GTN 和 PureSimulation 按快照轴布局动态执行三/四/五轴，禁止缺轴、隐式降阶、默认轴映射或 PureSimulation 回退。
- 降阶模式加工前低速定位锁定轴并复检；运行期间检测锁定轴漂移、失能、故障或限位并安全停止。
- `.lcnc`、CAM TOML 和点集升级到 v5。桌面端只读取 v5；`lcnc_project_upgrade` 将 v1–v4 写入不同的新 v5 文件并清除历史机床坐标。
- 工件安装姿态统一为机床配置语义：在机床模型功能区维护，不写入项目；CAM 刀路参数只保留加工模式。新项目默认选择当前物理构型支持的最高维加工模式。
- 机床坐标表和 Process 轴状态按布局动态显示；物理 XYZA 的 A 轴与五轴降阶模式的锁定倾斜轴按角色区分。

## 审查中修正的关键问题

- 修正刀路导出端点重复应用工件安装变换，确保模型、轮廓、刀路和机床坐标共用同一安装姿态。
- 加强拓扑与模式校验：要求完整 XYZ、唯一轴角色和控制器索引、无父子环、有效软限位/周期/运动参数，以及模式所需的精确参与轴角色。
- 求解器注册、CAM 快照和 Process 预检改为严格匹配求解器 ID 与版本；平面三轴使用独立版本契约。
- 修正旧项目升级时旋转轴拓扑名称丢失，并明确将迁移后的机床坐标标记为待重算。
- 平面三轴统一将参与轮廓法线投影为固定刀束方向；四轴连续旋转按轴周期处理，无限位 XYZA 不再误判为锁定轴。
- Process 运动参数由配置工具中的空程速度、加速度和加加速度生成，不再为第四、第五轴写入默认零加加速度。
- 清理启动阶段适配器缓存初始化的悬空 QObject 访问，并补强快照布局有效性检查。

## 已实现验证

- CMake/Ninja `acs-gtn` 与 Visual Studio/MSBuild `vs-acs-gtn` 使用独立生成树完成 Debug 构建。
- 两条生成路线分别执行完整 CTest，均为 26/26 通过；覆盖架构门禁、启动冒烟、项目包升级、CAM/Process 回归、多构型求解及 SimulatorCMHP 集成路径。
- `git diff --check`、架构依赖检查、禁用旧项目 API 检查以及 Process 无 OCC 类型检查通过。
- Qt 中文翻译资源通过 `lrelease`，无 unfinished 条目。

## SDK 模拟器与纯逻辑证据

- SimulatorCMHP 覆盖 ACS Simulator 连接、程序加载、动态三/四/五轴指令路径、状态读取、错误传播和释放。
- PureSimulation 按相同布局推进参与轴并保持锁定轴目标；动态 AxisMap 覆盖物理 XYZA 与 XYZAC 降阶四轴的差异。
- GTN 完成 SDK 构建及三/四/五维 API、坐标系模式、有效掩码和重复轴校验的纯逻辑验证。
- 上述结果属于软件、SDK 构建和 SDK 模拟器证据，不等同于物理 ACS、GTN、激光器或摆头验收。

## 仍需现场或人工验证

- 不同真实机台的轴正方向、旋转中心、软限位、XYZAC/XYZBC 四轴锁定角（默认 +90°，必要时配置为 -90°）。
- 圆管、方管和异形恒定轴线管材的真实装夹、切缝位置、速度/脉冲换算及激光工艺。
- 摆头双枢轴、零位刀束、焦点长度和安装偏置标定；奇异区行为、刀头辅助模型及物理 TCP 精度。
- UI 人工验收：模式切换后的待重算反馈、旧预览隐藏，以及机床模型、工件、加工面、轮廓、刀路和刀头姿态同步。
- 物理硬件的急停、锁定轴漂移、失能/故障、掉线、长时间运行和恢复流程。

## 兼容性说明

- 生产桌面端不再直接打开 v1–v4；必须使用 `lcnc_project_upgrade` 并指定不同输出路径。
- 迁移保留几何、加工面、轮廓、图层、顺序、参数和工具快照；历史机床坐标被清除，打开 v5 后必须重新求解。
- 软件求解输出为非 RTCP 机床轴坐标；ACS/GTN 控制器 RTCP 保持关闭。
