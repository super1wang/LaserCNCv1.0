# LaserCNC v1.4.4 — 下刀点与轮廓联合求解

日期：2026-08-11

## 修复内容

- 将有效下刀点作为当前轮廓有序求解序列的首点，顺序为“下刀点 → 轮廓首点 → 后续轮廓点”。
- 下刀点继承上一轮廓末点的连续姿态分支，并与当前轮廓一起输出完整的 XYZ 与旋转轴坐标。
- 删除下刀点独立求解后只用轮廓首点旋转轴覆盖的逻辑，避免旧旋转分支的线性坐标与新旋转姿态混用，导致部分轮廓在 Y 轴等线性轴上定位到错误位置。
- 新增 AC 转台回归：构造两套产生不同 XYZ 的可达姿态分支，验证下刀点必须匹配当前轮廓连续分支的完整位姿，而非独立求解结果。
