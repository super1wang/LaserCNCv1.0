# v1.5.3 — 刀路坐标边界与碰撞性能修正

日期：2026-08-19

## 本次交付

- 明确 CAM、离线仿真与 Process 的起始位姿边界：CAM 运动计划和离线仿真从首轮廓下刀点开始，不读取当前切割头位置；只有 Process 在首轮廓、范围加工或续跑执行前使用控制器 APOS 规划并校验初始进入段。
- 将离线刀路求解、快照投影和碰撞扫描的未插补轴统一到加工模式锁定值或确定性零位，避免实时轴反馈改变已生成刀路和碰撞结果。
- 修复带安装位置工件的坐标转换：切割、引入节点的 TCP 与法线按各节点已求解姿态转换到机床世界坐标，工件安装变换只应用一次。
- 修复空程显示坐标系混用：空程参考曲线统一在冻结工件姿态下构造，显示时再统一应用当前 WPC；上升和下降段保持沿局部法线的直线，仅中间 Traverse 段进行曲线插值。
- 优化完整机台碰撞扫描的包围盒、网格预筛和精确 BRep 门禁范围，并增加主动源/被动源及各阶段耗时日志。
- 优化非机台工件代理模式：使用更精细的只读表面 BVH 前置执行刀尖外移探针，正常刀尖接触不再进入串行 BRep 精确距离，可疑刀体侵入仍保留精确复检。
