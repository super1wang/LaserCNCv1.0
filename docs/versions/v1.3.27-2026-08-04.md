# 补全加工面高亮初始显示姿态

**版本**：v1.3.27

**日期**：2026-08-04

**状态**：修复旋转轴不在零位时，点击选择加工面后预览高亮与模型存在夹角、不重合的问题。

## 本次交付范围

- 根因（v1.3.26 的遗留缺口）：v1.3.26 仅在 `refreshMachineTransforms`（运动 tick）里对加工面 AIS 施加 `computeWpcTransform`，而 `CamDisplayProjectionService::refreshMachiningFaces` 创建 AIS 时仍是恒等变换。当用户在旋转轴已处于非零位时点击选择加工面，`refreshMachiningFaceDisplay` 创建的高亮停在零位姿态（恒等），工件却处于当前旋转姿态，二者相差一个旋转角即“夹角”；轴在零位时二者都为恒等故重合，非零位时出现夹角。
- `refreshMachiningFaces` 增加 `const MachineKinematics* kinematics` 参数，在创建每个加工面 AIS 后、`Display` 之前立即施加 `kinematics->computeWpcTransform(entry.workpieceEntry)`，使高亮一出生即处于工件当前运动学姿态。
- `CamModule::refreshMachiningFaceDisplay` 透传 `kinematics()`。运动 tick 路径（v1.3.26 的 `updateMachiningFaceTransforms`）保留不变，继续负责后续轴运动时的跟随。
- 已核查变换本身正确：加工面 `workpieceEntry` 与工件挂载 entry 同源（`collectWorkpieceShapes` 与 `mountWorkpiece` 均取 `XcafUtils::entry(Workpiece label)`），`computeWpcTransform` 为精确匹配查找，且与工件 AIS 使用同一函数同一 entry，工件 AIS 形状与拾取面同属一个 `XcafUtils::shape` 子形状、坐标空间一致。故夹角仅源于初始显示未施加变换，而非变换合成错误。
