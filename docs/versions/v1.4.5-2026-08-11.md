# LaserCNC v1.4.5 — 全局加工面提取策略调整

日期：2026-08-11

## 实现内容

- 移除“自动识别”入口，将“最大连通面策略”设为通用默认策略；按顺滑连接划分面组，以总面积最大的外表面提取加工边界。
- 最大连通面不再依赖“外表面与截面求交”的管材专用选边逻辑；界面组仍以内部分组保留，用于轮廓法线、下刀点和安全方向校验。
- 将平面策略定义为工件坐标系 +Z 方向俯视可见的最上层外表面，支持水平面和曲面，并过滤下层面、孔壁、盲孔底面及内部曲面。
- 对开放竖直管件从最高处闭合边界构造圆环加工面，避免最大侧壁覆盖正确的顶端截面。
- 对密集孔模型先执行候选面外法线和面整体内外朝向预筛，再使用完整工件做首个命中校验；仅在稀疏采样失败时使用三角网格 UV 采样。
- 对复合 STEP 先按 XY 投影覆盖率过滤被更高组件完全遮挡的堆叠子件，并在后续轮廓阶段按实际面拓扑归属子件，避免共享 XCAF 条目导致加工面重复分配。
- 同步、异步、分阶段和全自动刀路入口统一使用相同的加工面选择结果；最大连通面始终直接提取自身边界，界面组只参与几何校验。
- 保留旧配置值兼容迁移：原自动识别与管材模式映射为最大连通面策略，原平面和手动模式保持原有数值语义。
