# 切割链表序号显示

**版本**：v1.3.33

**日期**：2026-08-06

**状态**：新增「切割链表序号显示」按钮，对标「切割路径显示」；激活后在 3D 视图按加工顺序在每条轮廓起点附近绘制序号，并随工件轴系姿态实时跟随。

## 本次交付范围

- 新增 view 层渲染器 `ContourOrderLabelRenderer`（`src/view/contour_order_label_renderer.{h,cpp}`），与 `TravelPathRenderer` 同构：调用方传入按加工顺序排好的轮廓起点序列（OCC-free 结构体），渲染器为每条轮廓构造一个 `AIS_TextLabel` 并 Display 到 GuiDocument。
- 定位与轴系绑定（关键点）：序号定位在轮廓真实起点（引刀线起点优先，无引刀线则用切割首点）。`AIS_TextLabel` 不响应 `SetLocalTransformation`（与 `AIS_Shape` 不同），故不能复用虚线渲染器的变换矩阵方案；改为用 `MachineKinematics::computeWpcTransform(workpieceEntry)` 把局部起点换算到世界坐标后直接 `SetPosition` 写入。轴系变化时 `updateTransforms` 重算世界坐标并 `SetPosition` + `RecomputePrsOnly`，序号随工件实时跟随。样式：暖黄字 + 黑描边底（`Aspect_TODT_DEKALE`）、固定屏幕像素高度（`SetZoomable(false)` + `SetHeight(16)`）、禁用拾取以免干扰轮廓多选。
- Process 侧状态/事件/命令：`ProcessModule` 新增 `m_contourOrderLabelVisible` 与 `isContourOrderLabelVisible()`/`setContourOrderLabelVisible()`；新增 `ContourOrderLabelVisibilityToggled` 事件（`process_events.h`）；新增 `CmdToggleContourOrderLabel` 命令（可勾选，发布事件）。
- Ribbon：注册命令并加入「加工顺序」面板，紧邻「切割路径显示」。新图标 `contour_order.svg`（深/浅主题各一份，已登记 `resources.qrc`）。
- CamModule 接线：订阅 `ContourOrderLabelVisibilityToggled` 驱动显隐；将 11 处几何/顺序变更点的 `refreshTravelPath()` 统一改为 `refreshCuttingOrderOverlays()`（同时刷新虚线与序号，各自按自身可见性早退，互不影响）；`refreshMachineTransforms` 两个重载都加了序号 `updateTransforms` 调用；`clearToolpathViewState` / `onCamDataLoaded` 均刷新序号。
- 翻译：`lasercnc_zh_CN.ts` 补齐按钮文案「切割链表序号显示」与状态提示。
