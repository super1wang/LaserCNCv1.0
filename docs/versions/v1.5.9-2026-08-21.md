## 整改结果

- ULTRON 使用 RAII 和有界纯协议解析；Raycus/QCW 同步清理裸缓冲区、错误参数检查和失败返回，real-laser 变体不再报告原安全告警。
- ACS/GTN 可轮询等待使用 monotonic deadline、取消检查和有限间隔；状态轮询合并到模块单一全局优先级设备队列。
- CAD 文件读取只在 worker 构造 detached payload，所有者线程按 document id 提交；文档任务独立跟踪、取消和关闭。
- Simulation 通过 `ICamOfflineSimulationProvider` 捕获不可变 revision 快照；Process/Simulation 均不再查找具体 `CamModule`。
- ServiceRegistry 引入显式 borrowed 注册，CAM pipeline 删除可变容器外泄，CMake target 可见性和版本源完成收紧。
- `bdaqctrl.h` 迁入 `3rd/include_3rd/advantech/`；`setting/` 合并到 `settings/schema/`；公共头、数学常量、格式基线和架构门禁同步更新。
- 全机碰撞仍是离散节点验证，连续扫掠、保守细分和重规划保留为下一版本 P0。

完整证据、文件定位和优先级见 [AUDIT.md](../../AUDIT.md)，执行清单见 [todo.md](../../todo.md)。
