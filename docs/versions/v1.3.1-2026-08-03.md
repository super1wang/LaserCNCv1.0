# LaserCNC 加工面复用确认与刀路生成入口统一

**版本**：v1.3.1

**日期**：2026-08-03

**状态**：源码审阅、ACS+GTN Debug 构建与自动化测试通过；操作员交互与实际工件刀路结果仍需运行验收。

## 本次交付范围

- 将右侧刀路面板的生成请求统一路由 `CmdGenerateToolpath`
  执行，与 Ribbon 全局生成入口共享相同的预检和交互逻辑。
- 在非手动选面策略下保留了人工加工面时，全局生成前由操作员明确选择：
  清除后重新自动分离、沿用当前加工面，或取消操作。
- 为全自动刀路任务增加加工面处理模式。“沿用当前加工面”使用
  显式面集合提取路径，不再重新自动分类，成功提交时也不覆盖当前面集合。
- 增加当前面集合是否包含人工加工面的查询接口，并补齐新增确认框的
  英文源文、中文翻译注释及 `lasercnc_zh_CN.ts` 词条。

## 审阅结论与修正

- 复核了加工面修订戳、工件源归属、加工面/横截面角色、后台结果过期拒绝与成功后阶段链提交逻辑，未发现阻断提交的逻辑缺陷。
- 补齐新增确认框标题紧邻的 `中文翻译：...` 注释，使可见字符串符合当前本地化约定。
