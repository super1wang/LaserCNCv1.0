# LaserCNC v1.5.5（2026-08-19）

## 交付范围

- 修复切割轮廓应用法向偏置后严重变形的问题：偏置显示不再把整条闭合轮廓拟合成周期三次 B 样条。
- 使用严格经过全部可执行偏置采样点的一次 B 样条构造紧凑折线；每个区间保持直线、尖角保持 C0 连续，不再出现跨原始边的圆化和过冲。
- 零切割偏置直接复用原始 `TopoDS_Wire`，避免无偏置场景仍重建并改变轮廓拓扑。
- 新增闭合矩形回归测试，覆盖偏置点不漂移、四个尖角不丢失、曲线次数固定为一以及零偏置保留原始拓扑。

## 根因与边界

- `buildOffsetDisplayShape()` 曾把整条轮廓的全部偏置采样点一次性交给 `GeomAPI_Interpolate`，生成周期三次 B 样条。该全局光顺会跨越直线、尖角及相邻源边，导致长直段弯曲、尖角圆化，窄槽和急转处还可能产生回折。
- 本次改为单个一次 B 样条 Edge，在不增加大量拓扑 Edge 和选择实体的前提下精确表达实际采样折线，避免大型轮廓的额外内存与交互开销。
- 本次只修复 CAM 和离线仿真使用的偏置轮廓显示几何；基础离散点、加工法线、CAM 导出快照及 Process 逐点 `lineTo` 执行契约均未改变。
