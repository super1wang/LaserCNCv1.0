# 碰撞检测与安全域实施状态

更新日期：2026-08-24

上层审计与优先级：[AUDIT.md](../AUDIT.md)、[todo.md](../todo.md)
安全包格式：[machine_safety_package.md](machine_safety_package.md)

本专项已从早期的“C0～C3 稠密场 + 在线精确 OCCT”设想收敛为生产基线：

```text
离线：机台 STEP -> .lmsi -> .lmsp
Job：唯一运行时几何变量“工件” -> 局部保守场 / Job Overlay
规划：Machine LMSI AND Workpiece Field -> Surface-BVH/Coal 极窄残差 -> 连续运动证书
执行：Process 只校验证书/许可证，不做 OCC 或在线精确几何
审计：OCCT exact 仅用于离线 CertifiedSafe 反向抽样
```

`.lmsi` 不要求独自覆盖全部配置空间。它负责保守、极快地认证大部分安全区域；
BoundaryUnknown 只允许由有预算的 Surface-BVH/Coal 消解并固化为边证书。任何构建中、Unknown、过期或不匹配状态
在真实加工中都失败关闭。

### 离线 Coal 三组对照（2026-08-23）

测试统一使用现有生产 `.lmsi`、AC 转台真实 STEP 和固定随机序列的 1,000 个全域 APOS。
只有“整个网格单元”可被保守证明时才允许写回 CertifiedSafe；单点 Coal 无碰撞不能写回安全包。
为防止大 `security_margin` 遍历完整三角网格，先运行运动包络 AABB 证明，且仅当最大单元运动包络
不超过 0.25 mm 时才允许进入 Coal，否则保持 BoundaryUnknown。

| 组别 | 策略 | CertifiedSafe 覆盖 | 相对 A 提升 | 新增安全样本 | Coal 体对查询 |
|---|---|---:|---:|---:|---:|
| A | 当前默认 LMSI | 91.1% | - | - | 0 |
| B | LMSI + 当前叶单元离线 Coal | 91.1% | 0.0 pp | 0 | 0 |
| C | LMSI + level-3 热区细化 + 离线 Coal | 91.8% | +0.7 pp | 7/1000 | 0 |

64 个独立 OCCT 审计点中，C 比 A/B 额外认证 6 个 exact-safe，B/C 假安全均为 0。
C 的本轮提升全部来自 level-3 后 AABB 运动包络变紧，Coal 本身没有获得满足 0.25 mm 预算的单元。
未加预算的实验即使只取 1,000 个全域样本也在 15 分钟内未完成，已按构建门槛终止；
因此不应把“大单元直接交给 Coal”接入默认构建器。

同轮在线基准仍显示 Coal 对单点 Unknown 有价值：100,000 APOS 中 LMSI 处理 91,229，
Coal 对余下 8,771 个姿态认证安全 5,376、失败关闭 3,395；组合 P99 为 162.3 us。
半球路径 2,664 条边全部获得连续证书，证书构建 12.3933 ms，Process 查证 P99 为 0.2 us。

结论：离线覆盖率的有效提升来自更深的局部网格细化，不是把当前粗单元直接交给 Coal。
Coal 继续用于在线/后台 Unknown 消解和连续运动证书；若要让它参与离线包写回，必须由真实路径热区
继续细分到运动包络足够小，并采用预算、断点和缓存，不能全域运行。

### 默认包 / 高精包搭配 Coal 对照（2026-08-23）

三组均使用相同的 AC 转台模型、0.1 mm 全碰撞面网格、100,000 个固定随机 APOS、
64 个独立 exact 审计点和半球真实路径。高精持久档由既有 level-1 检查点补写 6/6 部件
三角网格，不改变 LMSI 覆盖率。

| 指标 | 默认 87.643% + STEP Coal | 高精 91.284% + STEP Coal | 高精 91.284% + 持久网格 Coal |
|---|---:|---:|---:|
| 索引加载 | 314 ms | 607 ms | 619 ms |
| STEP/Coal 模型准备 | 11,387 ms | 11,494 ms | 987 ms |
| Coal 回退 | 12,426 / 12.426% | 8,771 / 8.771% | 8,771 / 8.771% |
| fallback P50 / P95 / P99 | 3.4 / 213.7 / 691.3 us | 11.0 / 299.9 / 844.7 us | 10.8 / 293.6 / 839.7 us |
| 100k 查询总耗时 | 596.394 ms | 591.628 ms | 580.765 ms |
| 全体平均 / P99 | 5.964 / 137.4 us | 5.916 / 138.3 us | 5.808 / 135.6 us |
| 半球路径 Unknown 边 | 40 | 8 | 8 |
| 运动证书 Coal 体对查询 | 7,660 | 4,920 | 4,920 |
| 运动证书构建 | 15.716 ms | 11.003 ms | 11.096 ms |
| Process 查证 P99 | 0.2 us | 0.2 us | 0.2 us |
| exact 审计假安全 | 0 | 0 | 0 |

87.643% 到 91.284% 使随机回退次数减少 29.4%，但全域总耗时只减少约 0.8%。
原因是新增 LMSI 覆盖优先消除了便宜 Unknown，剩余姿态集中于真实碰撞边界，单次 Coal 更难；
而且两档回退率都高于 1%，全体 P99 仍然必然落在 Coal 路径。因此若目标是让任意 APOS 的
P99 进入 LMSI 快路径，真实工作负载覆盖必须高于 99%，不能只从 87% 提高到 91%。

高精包对真实路径更有价值：Unknown 边减少 80%，证书构建缩短约 30%，而 Process 查询不变。
持久网格把模型准备从约 11.5 s 降到 0.99 s（约 91.4%），但不会明显降低单次 Coal 查询时间；
它保存的是三角数据，加载后仍重建相同 OBBRSS BVH。测试持久索引为 39,268,037 B，仍低于 100 MiB。

测试还关闭了一个安全问题：旧 Surface 模型在混合实体中只保留实体外壳，会丢失同一部件的开放面/壳，
0.1/0.5 mm 持久网格均在审计中产生 7/64 假安全。现在持久化全部碰撞面，并在 Coal 分离后补充
封闭实体包含检测；审查又进一步把“全部面距离 BVH”和“仅封闭实体包含 BVH”拆开，避免开放面改变
射线奇偶导致漏判实体内部。修复后的 STEP、schema 5 持久路径和混合实体回归均为 false-safe = 0。

最快检索的后续优化优先级：

1. 默认安全包持久化完整、经审计的 0.1 mm 三角网格；模型启动不再依赖 STEP 三角化。
2. 用真实 Rapid/LeadIn/Cutting/点动轨迹反馈细化 Unknown，使实际工作负载覆盖先超过 99%；
   全域均匀提高体积覆盖的收益很低。
3. 对 Coal fallback 使用 blocking-pair 优先级、相邻 APOS/GJK guess 缓存和短时姿态证书；
   对难边界按碰撞对分别统计并定向优化。
4. 将共享 `CoalCollisionPair` 的互斥上下文改为每工作线程独立查询上下文，保留只读 BVH 共享，
   避免后台批量预测被单个 pair mutex 串行化。
5. 增加两级保守几何：粗 BVH/凸代理只负责快速明确分离，局部精细 BVH 处理候选；
   任一简化误差必须进入 separation guard，不能通过降低网格精度换速度。
6. 若仍需缩短约 1 s 的启动，可在 `.lmsp` 中增加带 Coal 版本、标量类型、端序和构建参数指纹的
   可选 OBBRSS 节点缓存；不匹配时从持久三角网格重建。它只优化启动，不优化单次查询。

### 高精表面 BVH 档

0.5 mm OCCT 表面三角化运行 911 s 后仍未写出基网格检查点，已超过 15 分钟门槛并终止。
因此表面 BVH 保留为显式离线高精档或后续增量资产，不作为一键生产包默认项。
这只影响 Unknown 消解率和初始化成本，不会制造假安全；默认叶级 BVH 仍为保守认证。

## 发布门禁

- 所有 CertifiedSafe 抽样不得出现假安全；一旦出现立即阻断发布。
- BoundaryUnknown 在真实加工和手动运动中必须失败关闭。
- 机台包、Job Overlay、运动边证书或许可证处于构建中/失效/过期时不得真实运动。
- `.lmsi` 包 ≤ 100 MiB；一键档 ≤ 15 分钟；exact 占比 ≤ 10%。
- 任意 APOS 查询只要求后台线程可用；硬实时只消费预先构建且与实际运动完全一致的证书/许可证。
- 自动化、GUI、SDK 模拟器和实体机证据分别记录，不相互替代。
