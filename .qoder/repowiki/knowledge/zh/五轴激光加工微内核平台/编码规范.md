- 文件名使用 snake_case，类名 PascalCase，成员变量 m_camelCase，常量 kCamelCase。
- .cpp 包含顺序严格遵循：自身头文件 → core → view → modules → app → 第三方库 → 标准库。
- 日志宏必须携带全限定 LogCode（如 LCNC_ERR(lcnc::LogCode::Xxx, ...)），且每个 catch 块必须记录 ERR 日志。
- 核心算法层（core/algorithms）禁止依赖任何 Qt UI 组件、LcncDocument 或 Kernel 全局状态。
- 新代码禁止使用 projectDocument() 等遗留 API，必须显式调用 workpieceDocument()/machineDocument()/camDocument()。
