- **核心编排**：`Kernel` 作为全局唯一入口，管理 `ModuleRegistry`（拓扑排序启动 cad→cam→process）、`ServiceRegistry`（服务定位）和 `EventBus`（跨域解耦通信）。
- **分层契约**：强制执行 `app → modules → view → core/algorithms → core` 的单向依赖链，禁止底层反向引用 UI 或模块层。
- **数据隔离**：采用三域文档模型（Workpiece/Machine/CAM），各域拥有独立的 `LcncDocument` 容器，通过 `GuiDocument` 统一渲染但逻辑隔离。
- **边界防护**：Process 模块严禁包含 OCC 几何头文件，仅通过 DTO（`ToolpathExportSnapshot`）消费 CAM 数据，确保执行层与几何层的物理隔离。
