- **硬件抽象层**：通过 `include_3rd` 目录下的 `ACSC.h` (ACS Motion Control) 和 `gts.h` (固高科技) 提供底层运动控制器的 C/C++ API 接口。
- **图形与多媒体支撑**：在 `runtime` 目录下组织 Qt6 框架组件、OpenCASCADE (TK*) 几何建模库以及 FFmpeg (av*) 多媒体处理库的 Debug/Release 动态链接库。
- **基础工具链**：集成 `spdlog` (高性能日志)、`toml11` (配置解析) 和 `magic_enum` (枚举反射) 等 Header-only C++ 库，为上层业务提供通用技术支撑。
- **资源隔离设计**：采用 `lib_3rd` 存放静态库，`runtime` 存放动态库，并通过 `bin_debug` 和 `bin_release` 实现构建变体的物理隔离。
