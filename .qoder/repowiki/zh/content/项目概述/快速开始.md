## 简介
本指南面向首次参与 LaserCNC 项目开发的工程师，提供从环境准备到首次运行的完整路径。LaserCNC 是一个基于 Qt 6 和 OpenCASCADE 的激光加工 CAD/CAM/Process 工具链，采用 CMake 构建系统，支持多模块扩展（CAD、CAM、Process）。本指南将重点覆盖以下内容：
- 开发工具链：CMake 3.20+、MSVC 2022 x64、Qt 6.9.1、OpenCASCADE 7.9.0
- 项目克隆与依赖准备
- 构建配置与编译参数
- Process 模块设备 SDK 启用方式
- 常见编译问题排查
- 首次运行验证与基础操作

## 开发环境准备
为确保顺利编译和运行，请按以下顺序准备开发环境。

- CMake 3.20 或更高版本
  - 官方下载地址：https://cmake.org/download/
  - 建议选择 Windows x64 版本并加入系统 PATH

- MSVC 2022 x64
  - 使用 Visual Studio Installer 安装“使用 C++ 的桌面开发”工作负载
  - 确保包含 MSVC v143 工具集和 Windows SDK

- Qt 6.9.1（MSVC 2022 x64）
  - 官方下载地址：https://www.qt.io/download
  - 安装时选择“自定义安装”，勾选 Qt 6.9.1 和 MSVC 2022 64-bit 组件
  - 将 Qt 安装目录添加到系统 PATH，或在 CMake 中通过变量指定

- OpenCASCADE 7.9.0（MSVC 2022 x64）
  - 官方下载地址：https://www.opencascade.com/doc/occt-7.9.0/overview/html/index.html
  - 选择 Windows x64 + Visual C++ 14.4（对应 VS 2022）版本
  - 建议下载“Combined”包，包含 OpenCASCADE 及其第三方依赖

- SARibbon（可选，用于界面）
  - 项目中已内置 SARibbonBar 的 CMake 配置，需确保安装目录正确

- 其他依赖
  - Qt SerialPort（用于串口通信，按需启用）
  - 第三方库：spdlog、magic_enum、toml11（项目已内置）

## 构建配置详解
本节说明如何生成和配置项目构建系统。

- 生成构建系统
  - 在项目根目录创建 build 子目录
  - 打开 VS 2022 x64 Native Tools Command Prompt
  - 进入 build 目录，执行 CMake 配置命令（示例命令行参数见下方）

- 关键 CMake 变量与路径
  - LCNC_OCCT_ROOT：OpenCASCADE 根目录
  - OpenCASCADE_DIR：OpenCASCADE cmake 目录
  - LCNC_SARIBBON_ROOT：SARibbon 根目录
  - SARibbonBar_DIR：SARibbonBar CMake 包目录
  - LCNC_WITH_ACS/GTN/BDAQ/REAL_LASER：Process 设备 SDK 启用开关

- 生成命令示例（请根据实际路径调整）
  - cmake -G "Visual Studio 17 2022" -A x64 -S .. -B . -T host=x64 -DCMAKE_PREFIX_PATH="Qt安装路径" -DOpenCASCADE_DIR="OpenCASCADE cmake路径" -DLTTPS_SARIBBON_ROOT="SARibbon安装路径"

- 验证生成结果
  - 成功后会在 build 目录生成 Visual Studio 解决方案文件
  - CMake 输出会显示 Qt6、OpenCASCADE 版本信息

## 构建选项说明
Process 模块支持多种设备 SDK 的启用，通过 CMake 选项控制。启用后，编译器宏定义会被设置，源码中通过条件编译启用相应功能。

- 可用选项
  - LCNC_WITH_ACS：启用 ACS 运动控制器适配器
  - LCNC_WITH_GTN：启用 GTN 运动控制器适配器
  - LCNC_WITH_BDAQ：启用 BDAQ IO 适配器
  - LCNC_WITH_REAL_LASER：启用真实激光器适配器
  - LCNC_PROCESS_HAS_SERIAL_COMM：启用串口通信（由 CMake 自动检测）

- 编译器宏定义
  - 对应的宏定义名称为 LCNC_PROCESS_HAS_ACS、LCNC_PROCESS_HAS_GTN、LCNC_PROCESS_HAS_BDAQ、LCNC_PROCESS_HAS_REAL_LASER、LCNC_PROCESS_HAS_SERIAL_COMM
  - 宏值由 CMake 的布尔值转换而来

- 设备 SDK 头文件示例
  - BDAQ 控制器接口头文件位于 src/modules/process/device/MotionControl/bdaqctrl.h
  - 该头文件定义了设备信息、控制状态、场景类型等数据结构

## 编译与部署流程
完成配置后，即可进行编译与部署。

- 编译
  - 在 VS 2022 中打开生成的解决方案文件
  - 选择 Release/Debug 配置，点击生成解决方案
  - 若出现链接错误，请检查依赖库路径与架构匹配

- 部署
  - CMake 配置中包含自动复制 OpenCASCADE 和 SARibbon 运行时 DLL 的逻辑
  - 构建完成后，目标目录会包含可执行文件以及必要的 DLL
  - 如未自动复制，请手动将 OCC_BIN_DIR 和 SARIBBON_BIN_DIR 下的 DLL 复制到输出目录

- 重要提示
  - MSVC 编译时启用了 /FS（串行化 PDB 写入），避免多线程编译冲突
  - 启用了强制包含 windows.h，以避免与 OpenCASCADE 冲突

## 常见问题排查
以下列举开发过程中常见的编译问题及解决方法。

- LNK1168 错误（文件正被占用）
  - 现象：链接阶段提示无法写入输出文件，提示文件被占用
  - 原因：程序正在运行或被防病毒软件锁定
  - 解决：
    - 关闭已运行的 LaserCNC 进程
    - 暂时关闭实时保护或添加排除项
    - 以管理员权限重新运行 VS 命令提示符
    - 清理解决方案后重试

- OpenCASCADE 未找到或路径错误
  - 现象：CMake 报错找不到 OpenCASCADE
  - 原因：LCNC_OCCT_ROOT 或 OpenCASCADE_DIR 设置不正确
  - 解决：
    - 确认 OpenCASCADE Combined 包已解压到指定路径
    - 确认 OpenCASCADE_DIR 指向 cmake 目录
    - 重新生成构建系统

- Qt 未找到或版本不匹配
  - 现象：CMake 报错找不到 Qt 或版本不符
  - 原因：CMAKE_PREFIX_PATH 未设置或 Qt 安装不完整
  - 解决：
    - 在 CMake 配置时显式设置 -DCMAKE_PREFIX_PATH
    - 确保安装了 Qt 6.9.1 和 MSVC 2022 组件

- SARibbon 未找到
  - 现象：CMake 报错找不到 SARibbonBar
  - 原因：LCNC_SARIBBON_ROOT 或 SARibbonBar_DIR 设置不正确
  - 解决：
    - 确认 SARibbon 安装目录存在
    - 确认 SARibbonBar_DIR 指向 lib/cmake/SARibbonBar

- Process 设备 SDK 未生效
  - 现象：编译通过但设备功能不可用
  - 原因：未启用对应 CMake 选项或缺少头文件/库
  - 解决：
    - 在 CMake 配置时添加 -DLCNC_WITH_ACS=ON 等选项
    - 确认设备 SDK 的头文件和库路径已在 CMake 中设置

## 基本使用示例
以下给出几个常用的基础操作示例，帮助快速上手。

- 新建项目并保存
  - 通过“文件”菜单选择新建项目
  - 输入项目名称与保存路径，点击确定
  - 在“项目资源管理器”中查看项目树结构

- 导入几何模型
  - 在 CAD 模块中导入 STEP/IGES 等格式文件
  - 在图形视图中查看模型并进行缩放/旋转

- 创建激光工艺流程
  - 切换到 Process 模块
  - 添加“切割”节点，设置参数（如功率、速度）
  - 预览工具路径并导出 G-code

- 配置通信端点
  - 在设置中打开“通信设置”
  - 选择协议（HTTP/串口/TCP），填写主机、端口、超时等参数
  - 测试连接（Mock 协议无需真实设备）
